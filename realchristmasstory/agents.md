# Project Guide

## Architecture

This is a dependency-free static website intended for deployment on Netlify.

## Key Files

- `index.html`: Contains the page markup and all styling.
- `README.md`: Describes the project and local usage.
- `.netlify/results.md`: Summarizes the latest completed work.

## Conventions

- Keep the site dependency-free unless new requirements justify a framework.
- Use semantic HTML and accessible CSS.
- Keep styles colocated in `index.html` while the site remains a single page.
- Respect reduced-motion preferences when adding animation.

## Design Decision

The requested black page is intentionally minimal, with centered content and a restrained entrance animation.
